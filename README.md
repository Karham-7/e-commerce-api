E-commerce API

REST API интернет-магазина, разработанное на FastAPI.

Проект реализует базовую функциональность backend-части интернет-магазина: регистрацию и авторизацию пользователей, управление категориями и товарами, корзину и оформление заказов.

Архитектура

Проект использует разделение приложения на слои:

API
 ↓
Service
 ↓
Repository
 ↓
Database
API

Отвечает за HTTP-запросы и маршрутизацию.

Service

Содержит бизнес-логику приложения.

Repository

Отвечает за работу с базой данных.

Database

Содержит SQLAlchemy-модели и настройку подключения к PostgreSQL.

Асинхронная работа с базой данных

Приложение использует асинхронный SQLAlchemy:

AsyncSession
async_sessionmaker
create_async_engine
asyncpg

Все основные операции с базой данных выполняются асинхронно.

Запуск проекта через Docker
1. Клонировать репозиторий
git clone <repository-url>
2. Создать .env

На основе файла:

.env.example
3. Запустить проект
docker compose up --build

После запуска приложение будет доступно по адресу:

http://localhost:8000

Swagger UI:

http://localhost:8000/docs
Тестирование

В проекте реализованы базовые асинхронные тесты API.

Для запуска тестов:

pytest

Тесты используют отдельную тестовую базу данных PostgreSQL.
